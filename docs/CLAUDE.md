# CLAUDE.md - Documentation Assets

## Overview

The `docs/` directory contains documentation assets and supporting materials for the project.

## Current Contents

```
docs/
└── swagger-ui.png       # Screenshot of the Swagger UI interface
```

## Purpose

This directory stores:
- Screenshots and images for documentation
- Additional documentation files (guides, tutorials)
- Architecture diagrams
- API documentation assets

## Guidelines

### Adding Documentation Assets

1. Use descriptive file names (e.g., `architecture-diagram.png`)
2. Prefer web-optimized formats (PNG for screenshots, SVG for diagrams)
3. Keep file sizes reasonable for repository storage
4. Update references in README.md when adding new assets

### Generated Documentation

The primary API documentation is auto-generated by FastAPI:
- **Swagger UI**: Available at `/docs` endpoint
- **ReDoc**: Available at `/redoc` endpoint

These are generated from:
- Endpoint docstrings
- Pydantic model Field descriptions
- Router tags

### Documentation Best Practices

- Keep screenshots up-to-date with UI changes
- Use relative paths in markdown files
- Include alt text for accessibility
- Maintain documentation alongside code changes
